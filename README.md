# 작가작업실 JEJU CMS 테스트 환경

운영 홈페이지 jakgastudio.com과 별도인 테스트 전용 웹소스입니다. 기존 운영 사이트의 공개 이미지를 읽기 전용 URL로 사용합니다. Key Visual은 임시 대체 사진이며 최종 승인 사진과 동일하지 않습니다.

필수 환경변수: SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY
관리자 사용: Supabase Auth 사용자 생성 후 public.news_admins 테이블에 user_id 등록.

작업 대상은 이 저장소와 Vercel jakgastudio-temp뿐입니다. 운영 저장소 main은 수정하지 않습니다.
