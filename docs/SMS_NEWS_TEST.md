# 작가작업실 JEJU · 문자 알림 시스템 (테스트)

대상: **jakgastudio-temp.vercel.app** (운영 사이트 변경 금지)

## 화면

- 공개 홈페이지 `/#news` 진행 중 모임 하단: `빠르게 소식 받기` 버튼
- 2단계 팝업: 이름·휴대폰 번호·개인정보 동의·광고성 SMS 동의 → 6자리 인증번호(3분) → 완료
- 같은 영역 `문자 알림 해지`: 휴대폰 SMS 인증 후 구독 해지
- 관리자 `/admin/sms.html`: 기존 모임·행사 관리자 로그인, 수신동의자 목록·선택 발송·080 동기화·수신거부·발송 이력

## 계정 연결 시 필요한 설정

솔라피에 가입하는 것만으로 API 인증정보가 자동 연결되지 않습니다. 테스트 Supabase 프로젝트의 **Edge Functions → Secrets**에서 운영자가 직접 다음 이름으로 입력해야 합니다:

- `SOLAPI_API_KEY`: 솔라피 API Key
- `SOLAPI_API_SECRET`: 솔라피 API Secret
- `SOLAPI_SENDER`: 솔라피 계정에서 등록·승인받은 문자 발신번호 (숫자만 입력)

이 세 값이 없으면 공개 신청에서 실제 SMS를 보내지 않고 503 응답을 반환합니다. 관리자 화면에서도 발송 기능을 비활성화합니다. **비밀키를 GitHub 또는 홈페이지 HTML/JS에 넣거나 채팅으로 전송하지 마세요.**

설정 후 솔라피 발신번호 인증·계정 이용 상태·충전 잔액을 확인하고 실제 운영자의 휴대폰 한 대로 인증 및 해지를 검증하세요. 대량 발송은 그 이후에 시도하세요.

## 구조

- 테스트 Supabase 테이블: `sms_subscribers`, `sms_challenges`, `sms_campaigns`
- 테이블 전부 RLS 활성화 및 anon/authenticated 직접 접근 권한 차단
- Supabase Edge Function: `studio-sms-news` (서비스 키는 Edge 내부에서만 사용)
- 테스트 Vercel 홈페이지 → 테스트 Supabase 함수만 호출
- 관리자는 Supabase 로그인과 `news_admins` 권한을 모두 확인해야 데이터 접근 가능
- 인증번호는 해시로만 보관, 3분 만료, 최대 5회 시도, 90초 재요청 제한, 전화번호·IP별 일일 제한, 24시간 경과 기록 정리
- 전송 전 솔라피 080 수신거부 목록 조회/동기화, 구독해지 사용자 제외
- 광고성 메시지에 `(광고) 작가작업실 JEJU` 및 `무료수신거부: 080-500-4233` 자동 부착
- 한국시간 21:00~08:00 발송 차단
- 관리자 최종 승인 필수, 동일 행사/내용/수신 대상 조합 중복 요청 방지
- 1회 500명 이하 처리. 솔라피 API의 '접수'는 실제 단말 수신 성공 보장이 아님

## 현재 검증

- DB 3개 테이블 생성, 개인정보 직접 공개 접근 제한
- API 정상 제약 검증: SMS 설정 없는 경우 503, 비로그인 관리자 401, 잘못된 번호 400
- 관리자·방문자 JavaScript 문법 확인
- 실제 SMS 발송 및 080 목록 동기화는 SOLAPI 키·등록 발신번호 설정 전까지 검증 불가
- 관리자 실제 로그인부터 발송까지의 브라우저 E2E는 아직 미검증

## 주의

- 운영 사이트의 API 키/고객 정보와 분리된 테스트 Supabase를 사용합니다.
- 광고성 수신동의 철회, 개인정보 삭제 요청 및 발송사 위탁 고지는 운영 전에 개인정보 처리방침과 함께 검토해야 합니다.
- 테스트 사이트는 기존 noindex/nofollow 상태를 유지합니다.
