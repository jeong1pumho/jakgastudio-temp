# TEST — 모임·행사 CMS 및 공간대관 사례

작업 대상은 **jakgastudio-temp.vercel.app** 테스트 프로젝트 하나입니다.

## 공개 화면
- /#news : 진행 중 6개(7개 이상이면 펼치기), 종료 최근 6개
- /news : 종료된 모임·행사 9개씩 서버 렌더링 및 페이지 번호 (?page=2)
- /news?operator=rental : 종료된 대관 행사만 표시하고 같은 방식으로 페이지 번호 지원
- /news/:slug : 기존 상세 URL 유지, 콘텐츠 유형/운영 구분/외부 주최자 표시
- /#rental-program : 기존 공간대관 소개 유지, 아래에 실제 종료 대관 행사 최근 3개 노출. 사례 0개면 섹션 숨김
- 대관 행사 상세페이지 하단에서 /#rental-program로 이동

## 관리자
- /admin/ : 등록·조회·수정·삭제
- 콘텐츠 유형: reading/독서, writing/글쓰기, themed/주제모임, special/특별행사
- 운영 구분: studio/작가작업실 JEJU 운영, rental/대관 행사
- 대관 행사에는 external_organizer(1~160자) 필수
- 진행 상태 ongoing/진행 중, ended/종료 (일정으로 자동 변경되지 않음)
- 기존 사진 업로드 및 서식 편집 유지, 유형·운영 구분 필터, 미리보기, 삭제 확인 대화상자

## 데이터와 SEO
- Supabase 테스트 프로젝트: qrbavxempotptnmflqoq
- 기존 news_posts에 nullable 컬럼만 추가. **기존 게시물 4건은 운영 주체를 추정하지 않고 미분류로 보존**
- 기존 게시물을 수정·저장하려면 관리자가 실제 유형 및 운영 구분을 지정해야 함
- 페이지/상세 URL을 표준 링크로 연결. 메타제목·설명·canonical·CollectionPage/BlogPosting 유지
- 테스트 사이트는 **noindex, nofollow** 유지. 운영 사이트에 이 소스를 그대로 복사할 때는 별도 SEO 검토 필요
- 운영 GitHub/Supabase/Vercel 프로젝트는 변경하지 않음
